# Treetax website

This is a static website designed for free hosting on GitHub Pages.

## Before publishing
Replace the placeholder phone number and email in `index.html` with the actual business details.

## Free hosting
1. Create a GitHub account.
2. Create a new public repository named `treetax-website`.
3. Upload `index.html` and `style.css`.
4. In Settings → Pages, choose GitHub Actions or Deploy from branch/main.
5. Add the custom domain `treetax.in`.
6. In GoDaddy DNS, follow the DNS records GitHub provides for the custom domain.
